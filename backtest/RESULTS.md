# 백테스트 결과 보고서

> **2차 확장 검증(다중 자산·다중 시장)이 추가되었다. [아래 2차 보고서](#2차-확장-백테스트-다중-자산다중-시장-검증--전략-개편) 참고.**
> 핵심: 다양한 데이터에서 기존 전략의 엣지가 사라짐(풀링 PF 1.02) → **ADX 레인지 필터 + TP1 30%로 개편**(풀링 PF 1.65).

## 개요

`crypto-quant-entry-signals.pine`의 신호 로직을 파이썬(`backtest.py`)으로 동일하게 재현하여
실제 과거 데이터로 검증했다.

- **데이터**: Coinbase BTC/USD 1시간봉 20,111개 (2017-07-01 ~ 2019-10-17, 약 2.3년)
  - 출처: CryptoDataDownload (tensortrade 패키지 번들, 실거래 데이터)
  - 2017 불장 → 2018 폭락장 → 2019 회복장을 모두 포함
- **체결 가정 (보수적)**:
  - 봉 마감 확정 후 종가 진입, 동일 봉에서 손절/익절 동시 도달 시 **손절 우선**
  - 테이커 수수료 0.055%/사이드 반영 (바이비트 선물 기준), 펀딩비 미반영
  - 1포지션 원칙 (보유 중 신규 신호 무시)
- **트레이드 관리**: TP1(+1R) 도달 시 50% 익절 + 본절 이동 → 잔량 TP2 또는 본절 청산

## 핵심 결론

### 1. "과매도/과매수만으로 진입"은 엣지가 없다 → 다이버전스 필수 모드 권장

| 신호 모드 | 1h 결과 | 4h 결과 |
|---|---|---|
| 기본 (과매도 or Div) | 461회, 승률 41%, **PF 0.61 (전멸)** | 125회, 승률 38%, **PF 0.60 (전멸)** |
| **다이버전스 필수** | 116회, 승률 52%, PF 1.28 | **30회, 승률 57%, PF 1.48** |

RSI 과매도 단독 트리거는 강한 추세장에서 "떨어지는 칼날"을 계속 잡아 손절이 누적된다.
다이버전스(가격 신저점 + RSI 저점 상승)가 확인된 경우에만 반전 진입의 승률이 유의미했다.
→ **지표의 "다이버전스 필수" 옵션 기본값을 켜짐으로 변경함.**

### 2. 가격 손절폭은 4시간봉 기준 약 2%가 적정

손절폭 = 원금 손실 한도 ÷ 레버리지. 1시간봉 + 5배(손절폭 2%)는 변동성 대비 너무 타이트해
손절 빈도가 급증했다. 같은 2% 폭도 4시간봉에서는 유효했다 (신호 질이 높아지고 노이즈 감소).

### 3. 트레이드당 원금 리스크를 낮추면 수익 엣지를 유지한 채 MDD가 급감

4h · 다이버전스 필수 · TP2=3R 고정, 리스크 설정만 변경:

| 레버리지 | 트레이드당 리스크 | 승률 | PF | 누적수익 | **MDD** |
|---|---|---|---|---|---|
| 5x | 원금의 10% | 56.7% | 1.48 | +50.5% | **-34.4%** |
| 3x | 원금의 6% | 56.7% | 1.48 | +33.9% | -21.9% |
| **2x** | **원금의 4%** | 56.7% | 1.48 | +23.5% | **-15.0%** |
| 1x | 원금의 2% | 56.7% | 1.48 | +12.0% | -7.7% |

동일한 30개 트레이드에서 리스크 배분만 바뀐 것 — 손익비(엣지)는 그대로,
파산 위험(MDD)만 줄어든다. **트레이드당 원금 리스크 3~5%를 권장.**

### 4. 권장 설정 (4h · Div필수 · 2x · 리스크 4% · TP1=1R/TP2=3R)

- 30 트레이드 (2.3년, 월 약 1회) | 승률 56.7% | PF 1.48
- 누적 +23.5% (연환산 +9.6%) | MDD -15.0%
- 결과 분포: TP2 완주 9회 / TP1+본절 8회 / 손절 13회
- 연도별: 2017 +3.0% / 2018 +18.4% / 2019 +3.0% — **하락장(2018)에서 가장 강함**
  (반전 포착형 전략의 특성. 롱 14 / 숏 16으로 방향 균형)

## 한계와 주의사항 (반드시 읽을 것)

1. **데이터 시기**: 2017~2019 Coinbase 현물 데이터다. 이 환경의 네트워크 정책상 최신
   거래소 API 접근이 차단되어 최근 데이터 검증은 불가했다. 2024~2026 시장에서의 재현은
   저장소의 `crypto-quant-strategy-backtest.pine`을 트레이딩뷰 Strategy Tester에 올려
   비트겟/바이비트 무기한 심볼(예: `BYBIT:BTCUSDT.P`)로 직접 확인할 것.
2. **표본 수**: 권장 설정의 트레이드는 30회로 통계적으로 충분히 크지 않다. PF 1.48은
   "방향성 있는 근거"이지 보장이 아니다.
3. **과최적화 위험**: 여러 조합 중 사후적으로 좋은 조합을 고른 것이므로 실전 기대치는
   백테스트보다 낮게 잡아야 한다.
4. 펀딩비/슬리피지 미반영 (무기한 선물은 펀딩비가 유불리하게 작용할 수 있음).

## 재현 방법

```bash
cd backtest
pip install pandas numpy
python3 backtest.py data/Coinbase_BTCUSD_1h.csv   # 4개 기본 변형 비교
python3 sweep.py                                   # 타임프레임×리스크 전체 스윕
python3 refine.py                                  # 권장 설정 리스크 튜닝 + 전체 트레이드 내역
```

자기 데이터로 검증하려면 CSV(`date,symbol,open,high,low,close,volume_btc,volume`,
첫 줄 헤더 위 주석 1줄)를 만들어 `backtest.py <파일>`로 실행하면 된다.

# 2차 확장 백테스트: 다중 자산·다중 시장 검증 → 전략 개편

1차 백테스트가 BTC 2017~2019 단일 자산 기반이었으므로, 데이터를 8개 데이터셋으로
확장해 (1) 전략이 일반화되는지, (2) 개편할 규칙이 있는지 검증했다. 실행 스크립트:
`experiments.py`(일반화 + ablation), `experiments2.py`(ADX 필터 검증).

## 데이터 (전부 실거래 데이터)

| 데이터셋 | 기간 | 봉 수 | 출처 |
|---|---|---|---|
| BTC/USD 1h·4h | 2017-07 ~ 2019-10 | 20,111 | Coinbase (CDD) |
| BTC/USD 일봉 | **2013-04 ~ 2020-12** | 2,751 | Bitstamp (COVID 폭락 포함) |
| ETH/USD 일봉 | 2015-08 ~ 2020-12 | 1,940 | Poloniex |
| LTC/USD 일봉 | 2015-03 ~ 2020-12 | 2,022 | Poloniex |
| EURUSD 1h·4h | 2017 (1년) | 6,225 | Dukascopy (외환) |
| GOOGL 일봉 | 2009-05 ~ 2018-08 | 2,335 | 미국 주식 |

## 1단계: 일반화 검증 — 기존 권장 설정이 무너지는 곳 확인

기존 권장 설정(Div필수 · 2x · 리스크4% · TP1=1R 50% / TP2=3R)을 전 데이터셋에 그대로 적용:

| 데이터셋 | 트레이드 | 승률 | PF | 판정 |
|---|---|---|---|---|
| BTC 4h 17-19 | 30 | 56.7% | **1.48** | ✅ (1차에서 선택된 구간) |
| BTC 1h 17-19 | 118 | 50.8% | 1.07 | ⚠️ 한계선 |
| GOOGL 1D | 14 | 71.4% | **3.75** | ✅ |
| BTC 1D 13-20 | 11 | 27.3% | 0.69 | ❌ |
| LTC 1D 15-20 | 12 | 33.3% | 0.39 | ❌ |
| ETH 1D 15-20 | 12 | 16.7% | **0.23** | ❌ 최악 |
| EURUSD 1h/4h | 45 | 44% | 0.55~0.83 | ❌ |
| **풀링 (242 트레이드)** | 242 | 47.9% | **1.02** | **엣지 없음** |

**진단**: 역추세(반전 포착) 전략이라 강한 추세를 보이는 자산·구간(ETH/LTC 일봉 등)에서
"떨어지는 칼날 / 달리는 기차" 진입이 반복된다. 1차 결과(BTC 4h PF 1.48)는 부분적으로
선택 편향이었다.

## 2단계: 규칙별 ablation — 무엇을 남기고 무엇을 바꿀까

전 데이터셋 풀링 성과로 규칙을 하나씩 바꿔 비교 (기준 PF 1.02):

| 실험 | 풀링 PF | 판정 |
|---|---|---|
| MACD 조건 제거 | 0.88 | **유지** (제거 시 악화 — 조건이 유효함) |
| BB 터치 조건 제거 | 0.98 | **유지** |
| 본절 이동 없음 | 1.05 | 유지 (PF 비슷, 승률 48%→30% 급락) |
| 본절+0.25R 버퍼 | 0.91 | 기각 |
| **TP1 청산 비중 50%→30%** | **1.09** | **채택** (2차 목표를 더 크게 활용) |
| TP1 비중 70% | 0.95 | 기각 |
| ATR 1.5~2.0배 스탑 | 1.02~1.04 | 중립 — 현행 유지 |
| TP2=2R | 0.97 | 기각 (3R 유지) |
| TP2=4R | 1.02 | 중립 (3R 유지) |
| 쿨다운 5봉 | 0.96 | 기각 (10봉 유지) |
| EMA200 추세 필터 | 0.92 | 기각 |

## 3단계: 구조적 처방 — ADX 레인지 필터 (핵심 개편)

"추세가 강할 때 역추세 진입 금지"를 ADX(14)로 구현. **용량-반응 관계가 단조로워**
우연한 개선이 아니라는 근거가 된다:

| 필터 | 트레이드 | 승률 | 풀링 PF |
|---|---|---|---|
| 없음 (기준) | 242 | 47.9% | 1.02 |
| ADX < 30 | 95 | 49.5% | 1.26 |
| **ADX < 25 (채택)** | **65** | **53.8%** | **1.50** |
| ADX < 20 | 34 | 52.9% | 1.81 |
| **ADX < 25 + TP1 30% (최종 개편안)** | **65** | **53.8%** | **1.65** |

개편안의 데이터셋별 효과:
- **ETH 일봉: 진입 0회** — 최악의 손실원을 필터가 원천 차단 (ETH는 늘 추세가 강함)
- BTC 1h: PF 1.07 → **1.41** (+17.2%, 30 트레이드) — 시간봉이 다시 쓸 만해짐
- BTC 4h: PF 1.48 → 1.95 (단, 5 트레이드로 급감)
- GOOGL 1D: PF 3.75 → 5.99
- 잔여 약점: LTC 일봉은 필터 후에도 4 트레이드 손실 — 일봉 크립토 역추세는 여전히 비추천

## 최종 개편 내역 (파인 스크립트 반영 완료)

1. **ADX(14) < 25 레인지 필터 추가, 기본 켜짐** — 지표/전략 공통. 차트 테이블에
   "레인지(진입 가능) / 추세(진입 차단)" 상태 표시.
2. **TP1 청산 비중 50% → 30%** — 잔량 70%가 TP2(3R)를 노림.
3. 유지: 다이버전스 필수, MACD/BB 조건, 본절 이동, TP2=3R, 쿨다운 10봉,
   스윙+한도 스탑, 트레이드당 리스크 3~5%.

## 한계 (1차 보고서의 주의사항에 추가)

- 개편안 트레이드 수는 풀링 65회로 더 줄었다. 필터가 강해질수록 통계적 표본은 작아진다.
- ADX 임계값 25는 20~30 구간에서 모두 개선을 보였으므로 특정 값에 과최적화된 것은
  아니지만, 실전에서는 25 고정보다 "20~30 사이 어디서도 수익"이라는 사실이 더 중요하다.
- EURUSD 데이터는 2017년 1년치뿐이고, 크립토 일봉 데이터는 2020-12에서 끝난다.
  2021 이후 구간은 트레이딩뷰 Strategy Tester로 직접 확인할 것 (개편안이 기본값으로
  반영된 `crypto-quant-strategy-backtest.pine` 사용).
- 신호 빈도가 낮아진 만큼(1h 기준 월 1~2회) 여러 심볼을 동시에 관찰하는 운용을 권장.

## BTC 1h 상세 (실전 주력 타임프레임)

- 30 트레이드 / 승률 50% / PF 1.41 / 최종 자본 1,000 → 1,172 USDT (+17.2%) / MDD -22.6%
- 결과 유형: TP2 완주 8 / TP1+본절 7 / 손절 15
- 연도별: 2017 -0.4% / **2018 +20.4% (승률 64.3%)** / 2019 -1.0%
- 롱 8회 -7.2% vs **숏 22회 +26.2%**

## 몬테카를로 스트레스 테스트 (풀링 65 트레이드, 순서 셔플 5,000회)

- 최종 자본 배수 1.60x (곱셈 수익률이라 순서 무관하게 동일)
- **MDD 분포: 중앙값 -18.3%, 최악 5%ile -28.2%** — 운이 나쁘면 -28% DD까지 각오할 것
- 원금 손실로 끝나는 시나리오: 0% (65 트레이드 기준)

## 3차 검증에서 새로 드러난 주의사항

1. **수익의 시기 집중**: BTC 1h 수익이 사실상 2018년(레인지·하락장)에 몰려 있고
   2017·2019는 본전 수준. 이 전략은 "횡보·하락 국면에서 버는 전략"이다.
   강한 상승장에서는 신호 자체가 드물고 수익 기여도 작다.
2. **숏 편향**: 검증 구간에서 수익 대부분이 숏에서 나왔다. 2017-19 구간 특성일 수
   있으므로 롱 신호는 특히 상위 타임프레임 지지 확인 후 재량 판단을 권장.
3. 신호 빈도: BTC 1h 기준 연 약 13회. 단일 심볼로는 드물다 — 지표를 여러 심볼
   (BTC/ETH/SOL 등 무기한)에 걸어 두고 신호를 모아서 운용할 것.
4. MDD -22.6%(BTC 1h)는 트레이드당 리스크 4% 기준이다. 이를 -15% 이내로 줄이려면
   리스크를 3%로 낮추면 된다 (수익도 비례 감소).

# 4차: 트레이딩뷰 실전 검증(2024~2026) 피드백 반영

사용자가 트레이딩뷰 Strategy Tester에서 개편안(2~3차 반영본)을 최신 데이터로 직접 검증했다:

## 트레이딩뷰 승률 착시 주의

TV는 분할 익절의 각 체결을 별도 "거래"로 집계한다. TP1 익절 + 본절 청산 한 건이
승리 1 + 패배 1(본절은 수수료만큼 소손실)로 나뉘므로 표시 승률(34%)은 진입 기준
승률보다 낮게 보인다. 진입 기준 성과는 PF와 순손익으로 판단할 것.
