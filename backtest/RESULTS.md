# 백테스트 결과 보고서

## 개요

`crypto-quant-entry-signals.pine`의 신호 로직을 파이썬(`backtest.py`)으로 동일하게 재현하여
실제 과거 데이터로 검증했다.

- **데이터**: Coinbase BTC/USD 1시간봉 20,111개 (2017-07-01 ~ 2019-10-17, 약 2.3년)
  - 출처: CryptoDataDownload (tensortrade 패키지 번들, 실거래 데이터)
  - 2017 불장 → 2018 폭락장 → 2019 회복장을 모두 포함
- **체결 가정 (보수적)**:
  - 봉 마감 확정 후 종가 진입, 동일 봉에서 손절/익절 동시 도달 시 **손절 우선**
  - 테이커 수수료 0.055%/사이드 반영 (바이비트 선물 기준), 펀딩비 미반영
  - 1포지션 원칙 (보유 중 신규 신호 무시)
- **트레이드 관리**: TP1(+1R) 도달 시 50% 익절 + 본절 이동 → 잔량 TP2 또는 본절 청산

## 핵심 결론

### 1. "과매도/과매수만으로 진입"은 엣지가 없다 → 다이버전스 필수 모드 권장

| 신호 모드 | 1h 결과 | 4h 결과 |
|---|---|---|
| 기본 (과매도 or Div) | 461회, 승률 41%, **PF 0.61 (전멸)** | 125회, 승률 38%, **PF 0.60 (전멸)** |
| **다이버전스 필수** | 116회, 승률 52%, PF 1.28 | **30회, 승률 57%, PF 1.48** |

RSI 과매도 단독 트리거는 강한 추세장에서 "떨어지는 칼날"을 계속 잡아 손절이 누적된다.
다이버전스(가격 신저점 + RSI 저점 상승)가 확인된 경우에만 반전 진입의 승률이 유의미했다.
→ **지표의 "다이버전스 필수" 옵션 기본값을 켜짐으로 변경함.**

### 2. 가격 손절폭은 4시간봉 기준 약 2%가 적정

손절폭 = 원금 손실 한도 ÷ 레버리지. 1시간봉 + 5배(손절폭 2%)는 변동성 대비 너무 타이트해
손절 빈도가 급증했다. 같은 2% 폭도 4시간봉에서는 유효했다 (신호 질이 높아지고 노이즈 감소).

### 3. 트레이드당 원금 리스크를 낮추면 수익 엣지를 유지한 채 MDD가 급감

4h · 다이버전스 필수 · TP2=3R 고정, 리스크 설정만 변경:

| 레버리지 | 트레이드당 리스크 | 승률 | PF | 누적수익 | **MDD** |
|---|---|---|---|---|---|
| 5x | 원금의 10% | 56.7% | 1.48 | +50.5% | **-34.4%** |
| 3x | 원금의 6% | 56.7% | 1.48 | +33.9% | -21.9% |
| **2x** | **원금의 4%** | 56.7% | 1.48 | +23.5% | **-15.0%** |
| 1x | 원금의 2% | 56.7% | 1.48 | +12.0% | -7.7% |

동일한 30개 트레이드에서 리스크 배분만 바뀐 것 — 손익비(엣지)는 그대로,
파산 위험(MDD)만 줄어든다. **트레이드당 원금 리스크 3~5%를 권장.**

### 4. 권장 설정 (4h · Div필수 · 2x · 리스크 4% · TP1=1R/TP2=3R)

- 30 트레이드 (2.3년, 월 약 1회) | 승률 56.7% | PF 1.48
- 누적 +23.5% (연환산 +9.6%) | MDD -15.0%
- 결과 분포: TP2 완주 9회 / TP1+본절 8회 / 손절 13회
- 연도별: 2017 +3.0% / 2018 +18.4% / 2019 +3.0% — **하락장(2018)에서 가장 강함**
  (반전 포착형 전략의 특성. 롱 14 / 숏 16으로 방향 균형)

## 한계와 주의사항 (반드시 읽을 것)

1. **데이터 시기**: 2017~2019 Coinbase 현물 데이터다. 이 환경의 네트워크 정책상 최신
   거래소 API 접근이 차단되어 최근 데이터 검증은 불가했다. 2024~2026 시장에서의 재현은
   저장소의 `crypto-quant-strategy-backtest.pine`을 트레이딩뷰 Strategy Tester에 올려
   비트겟/바이비트 무기한 심볼(예: `BYBIT:BTCUSDT.P`)로 직접 확인할 것.
2. **표본 수**: 권장 설정의 트레이드는 30회로 통계적으로 충분히 크지 않다. PF 1.48은
   "방향성 있는 근거"이지 보장이 아니다.
3. **과최적화 위험**: 여러 조합 중 사후적으로 좋은 조합을 고른 것이므로 실전 기대치는
   백테스트보다 낮게 잡아야 한다.
4. 펀딩비/슬리피지 미반영 (무기한 선물은 펀딩비가 유불리하게 작용할 수 있음).

## 재현 방법

```bash
cd backtest
pip install pandas numpy
python3 backtest.py data/Coinbase_BTCUSD_1h.csv   # 4개 기본 변형 비교
python3 sweep.py                                   # 타임프레임×리스크 전체 스윕
python3 refine.py                                  # 권장 설정 리스크 튜닝 + 전체 트레이드 내역
```

자기 데이터로 검증하려면 CSV(`date,symbol,open,high,low,close,volume_btc,volume`,
첫 줄 헤더 위 주석 1줄)를 만들어 `backtest.py <파일>`로 실행하면 된다.
