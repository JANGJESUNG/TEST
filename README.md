# TEST

## 퀀트 진입 타점 시그널 지표 (TradingView Pine Script)

`crypto-quant-entry-signals.pine` — 비트겟/바이비트 무기한 선물 트레이딩을 위한 복합 진입 타점 지표입니다.
트레이딩뷰 차트에서 직접 확인하고 **최종 판단은 본인이 내린 후** 거래소에서 실행하는 용도로 설계했습니다.

### 설치 방법

1. 트레이딩뷰 하단 **Pine 에디터** 열기
2. `crypto-quant-entry-signals.pine` 내용 전체를 붙여넣기
3. **저장 → 차트에 추가**
4. 지표 설정(톱니바퀴)에서 ⑥ 리스크 관리 항목의 **원금 / 레버리지 / 최대 손실 한도**를 본인 계좌에 맞게 수정 (필수)

### 진입 신호 로직

롱/숏 신호는 아래 조건이 **동시에** 충족될 때만 발생합니다 (봉 마감 확정 기준, 리페인팅 방지).

| 구분 | 롱 (▲ 청록 삼각형) | 숏 (▼ 적갈 삼각형) |
|---|---|---|
| RSI | 최근 과매도(<30) 진입 **또는** 상승 다이버전스 | 최근 과매수(>70) 진입 **또는** 하락 다이버전스 |
| 볼린저 밴드 | 최근 하단 밴드 터치 (지지 확인) | 최근 상단 밴드 터치 (저항 확인) |
| MACD | 히스토그램 상방 전환 또는 골든크로스 | 히스토그램 하방 전환 또는 데드크로스 |
| EMA (옵션) | 추세 필터 켜면 EMA200 위에서만 롱 | 추세 필터 켜면 EMA200 아래에서만 숏 |

- **다이버전스 필수** 옵션을 켜면 다이버전스가 확정된 경우에만 신호가 발생합니다 (신호 수 감소, 신뢰도 상승).
- 신호 간 **쿨다운**(기본 10봉)으로 연속 중복 신호를 차단합니다.

### 신호 발생 시 표시되는 정보

각 신호 라벨에는 다음이 함께 표시됩니다.

- **진입가** (신호 봉 종가)
- **손절가**: `원금 최대 손실 한도 ÷ 레버리지`로 가격 손절폭을 자동 환산
  - 예: 한도 -10%, 레버리지 5배 → 가격 기준 -2% 지점이 손절가
  - 스윙 저점/고점 기반 구조적 스탑이 더 타이트하면 그쪽을 채택 → **손실이 한도를 절대 초과하지 않음**
- **1차 익절 (보수적)**: 손절폭(R)의 1배 지점 — 도달 시 일부 익절 + 본절 스탑 이동 권장
- **2차 익절 (공격적)**: 손절폭(R)의 2배 지점
- **권장 수량**: 입력한 원금×레버리지 기준 수량
- **진입 근거**: RSI/다이버전스/BB/MACD/추세 상태를 항목별로 요약

우측 상단 테이블에서 현재 추세, RSI, MACD, BB 위치, 다이버전스 유효 여부, 한도 손절폭을 실시간 확인할 수 있습니다.

### 알림 설정

트레이딩뷰 알림 생성 시 조건으로 선택 가능:
- `롱 진입 신호` / `숏 진입 신호`
- `상승 다이버전스` / `하락 다이버전스`

### 권장 사용법 (리스크 관리 원칙)

1. **지표는 후보 타점 제시용**입니다. 상위 타임프레임 추세, 주요 지지/저항, 펀딩비, 주요 이벤트를 함께 확인 후 최종 판단하세요.
2. 진입 즉시 거래소(비트겟/바이비트)에 **손절 주문을 함께 등록**하세요. 라벨의 손절가를 그대로 사용하면 원금 대비 손실이 한도 이내로 제한됩니다.
3. 1차 목표 도달 시 50% 익절 후 손절가를 본절(진입가)로 올리는 것을 권장합니다. 이후 남은 물량은 2차 목표까지 홀딩.
4. 다이버전스 신호는 피벗 확정에 몇 봉의 지연이 있습니다(기본 3봉). 확정 전 미리 진입하지 마세요.
5. 15분봉 이하 단타보다는 **1시간봉 이상**에서 신호 신뢰도가 높습니다.

### 백테스트 결과 요약

신호 로직을 파이썬으로 재현해 실데이터로 2차에 걸쳐 검증했습니다. 상세 보고서: [`backtest/RESULTS.md`](backtest/RESULTS.md)

**1차 (BTC 1h, 2017~2019)**
- **다이버전스 필수 모드만 유효한 엣지 확인** — 과매도/과매수 단독 진입은 전 구간 손실(PF 0.6). 이 근거로 지표 기본값을 "다이버전스 필수 켜짐"으로 변경.
- 같은 신호에서 트레이드당 리스크만 10%→4%로 낮추면 엣지(PF)는 유지되고 MDD만 -34%→-15%로 급감. **리스크 한도는 3~5%를 권장.**

**2차 (8개 데이터셋: BTC 1h/4h/일봉 2013-2020 · ETH · LTC · EURUSD · GOOGL)**
- 다양한 데이터에서는 기존 설정의 엣지가 소멸(풀링 PF 1.02). 특히 추세가 강한 자산의 일봉(ETH PF 0.23)에서 역추세 진입이 반복 손실.
- **개편 ①: ADX(14) < 25 레인지 필터 추가 (기본 켜짐)** — 강한 추세장에서 진입 차단. 풀링 PF 1.02→1.50, 임계값 20~30 어디서나 개선(과최적화 아님). ETH 일봉의 손실 진입을 0회로 차단.
- **개편 ②: TP1 청산 비중 50%→30%** — 풀링 PF 추가 개선(→1.65). 잔량 70%가 2차 목표(3R)를 노림.
- 유지 근거 확보: MACD/BB 조건(제거 시 악화), 본절 이동(승률 방어), TP2=3R, 쿨다운 10봉.
- 개편 후 권장: **1h~4h 크립토 · 레버리지 2배 · 트레이드당 리스크 4%** (BTC 1h PF 1.07→1.41). 일봉 크립토 역추세는 필터 후에도 비추천.
- 최신 데이터 검증: `crypto-quant-strategy-backtest.pine`(개편안 기본 반영)을 Strategy Tester에 올려 `BYBIT:BTCUSDT.P` 등에서 직접 확인 가능.
- 한계: 개편안 풀링 표본 65 트레이드, 크립토 일봉 데이터는 2020-12까지, 펀딩비 미반영. 사후 선택 조합이므로 실전 기대치는 낮춰 잡을 것.
