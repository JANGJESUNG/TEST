# 페이퍼 트레이딩 가이드 (눌림목 전략 · BTC 1시간봉)

목적: 실제 돈을 걸기 전에 **신호 20개**로 전략의 실전 기대치를 측정한다.
이 기간의 목표는 수익이 아니라 **데이터 수집**이다.

## 1. 준비 (1회만)

1. `BITGET:BTCUSDT.P` (또는 BYBIT) **1시간봉** 차트에 `crypto-trend-pullback-signals.pine` 추가
2. 알림 2개 등록: 차트 우클릭 → **알림 추가** →
   - 조건: `눌림목 타점` → **롱 눌림목 신호**, 옵션 "봉 마감 시 1회"
   - 조건: `눌림목 타점` → **숏 되돌림 신호**, 동일 옵션
3. 만료 없음 / 앱 푸시 켜기

## 2. 신호가 오면 (건당 1분)

1. 차트에서 신호 라벨 확인 → `journal.csv`에 **라벨 값 그대로** 기록
   (진입가 / 손절가 / TP1 / TP2)
2. 해당 포지션의 청산 감시용으로 **가격 알림** 3개 추가 (손절가·TP1·TP2 지점)
3. **개입 금지.** "이번 신호는 느낌이 안 좋은데"라며 건너뛰지 말 것 —
   지금 측정하는 것은 전략이지 재량이 아니다. 전부 기록한다.

## 3. 포지션 관리 기록 규칙 (전략과 동일)

- TP1(1R) 터치 → "30% 익절" 처리, 이후 손절가를 **진입가(본절)**로 상향/하향
- 이후 TP2(4R) 터치 → 잔량 청산, 결과 = `TP2완주`
- 본절 터치 → 결과 = `TP1+본절`
- TP1 전에 손절가 터치 → 결과 = `손절`
- 같은 봉에서 손절/익절 동시 터치 시 **손절로 기록** (보수적 원칙)

## 4. 20개 채워지면

journal.csv를 공유한다. 판정 기준:

| 결과 | 행동 |
|---|---|
| PF ≥ 1.2 | 소액 실전 시작 (원금의 10~20%로 시작, 리스크 4%/트레이드) |
| PF 1.0~1.2 | 20개 추가 수집 후 재판정 |
| PF < 1.0 | 중단, 손실 트레이드 부검 후 재설계 |

실전 이후에도 동일 기록을 유지하고, **계좌 -15% 도달 시 무조건 중단**한다.

## 참고: 기대치 (백테스트 기준)

- 신호 빈도: 월 8~12회 (20개 ≈ 6~8주)
- 승률 35~50% — **손절 5~6연속은 정상 범위**다. 시스템 고장이 아니다.
- 수익은 TP2 완주(+4R)가 손절 여러 번을 갚는 구조. TP2 비중이 15~25%면 정상.
